#### Description:

TaskFlow is a single-page task management web application.

The application allows users to create and manage tasks in a simple
and organized way.

Users can:

- Add tasks
- Choose a category
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Search for tasks
- Filter tasks by status
- View task statistics

The application uses Local Storage so that tasks remain available
after the browser is closed and opened again.

## Technologies

TaskFlow was built using:

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Files

### index.html

Contains the structure and user interface of the application.

### style.css

Contains the styling and responsive design.

### script.js

Contains the application's functionality, including task creation,
editing, deletion, filtering, searching, statistics, and Local Storage.

### How to Run

Open `index.html` in a web browser.

No external libraries are required.
